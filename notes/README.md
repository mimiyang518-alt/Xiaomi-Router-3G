# Working Notes

This directory contains analysis derived from raw evidence.

Examples:

    UART boot comparison
    bootloader command notes
    partition map analysis
    NAND / SPI-NAND observations
    recovery hypotheses
    firmware provenance notes

Use these evidence labels:

    CONFIRMED
    INFERRED
    UNKNOWN
    UNTESTED

Whenever possible, point back to the exact raw log or dump that supports a conclusion.

Do not edit raw evidence to make it match a hypothesis.
