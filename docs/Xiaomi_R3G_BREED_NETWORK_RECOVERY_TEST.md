# Xiaomi Router 3G（R3G）Breed / 网络恢复测试记录

## 网卡原则
测试时只启用一个有线网卡，关闭 Wi‑Fi、VPN、虚拟网卡。

## 192.168.1.1
电脑：
IP 192.168.1.2
Mask 255.255.255.0
Gateway 192.168.1.1

CMD：
arp -d *
ping -t 192.168.1.1

结果：无响应。

## 192.168.31.1
电脑：
IP 192.168.31.2
Mask 255.255.255.0
Gateway 192.168.31.1

CMD：
arp -d *
ping -t 192.168.31.1

结果：无响应。

## LED 对比
普通启动：橙灯一直亮。
按住 RESET 启动：橙灯亮 → 灭一下 → 再橙灯常亮。

## 结论
RESET 确实改变启动行为，但 Breed/恢复网络没有建立。下一步进入 TTL/UART 日志诊断。
